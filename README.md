# 페이앤밴 포스기 무상 렌탈 상세페이지

피그마 `페이앤밴_렌탈 상세페이지` 의 `포스기(토스)렌탈` 페이지 디자인을 반응형 웹페이지로 옮긴 프로젝트입니다.
빌드 과정 없는 순수 HTML/CSS/JS 라서 `public` 폴더를 그대로 넷리파이에 올리면 됩니다.

## 폴더 구조

```
.
├── netlify.toml                 # 넷리파이 설정 (public 폴더 배포)
├── apps-script/
│   └── Code.gs                  # 구글 시트 저장 + 슬랙 알림 (Google Apps Script)
├── docs/
│   └── form-setup.md            # 시트·슬랙 연결 방법
└── public/                      # ← 실제로 배포되는 폴더
    ├── index.html               # 페이지 전체 마크업 (섹션별 주석으로 구분)
    ├── css/
    │   ├── base/                # 디자인 토큰(색·단위), 리셋, 공통 스타일·등장 애니메이션
    │   ├── components/          # 말풍선/알약, 쏟아지는 알약(drop), 자동 캐러셀, 기능 캐러셀, 신청 폼, 하단 버튼, 신청 창
    │   └── sections/            # 섹션별 스타일 (topbar, hero, benefit, reviews, lineup, apply, footer)
    ├── js/
    │   ├── config.js            # ★ 운영 설정: 신청 접수 주소, 업종 목록, 상담 시간
    │   ├── main.js              # 진입점
    │   ├── modules/             # 기능별 코드 (폼, 쏟아지는 알약, 캐러셀, 마키, 등장효과, 유입경로 저장 등)
    │   └── vendor/              # 물리 엔진 Matter.js (MIT, 쏟아지는 알약에만 사용)
    └── assets/
        ├── images/              # 피그마에서 추출한 이미지 (WebP)
        ├── icons/               # 이모지·로고·아이콘 (SVG)
        └── videos/              # 영상 넣는 곳 (README 참고)
```

| `.hero` | 00히어로 | 말풍선 팝업, 형광펜 그어짐, 혜택 알약·기기 세트 순차 등장 후 둥실둥실, 알약에 마우스를 올리면 기울어지며 떠오름 |

## 쏟아지는 알약 (`.drop`)

- 코드: `js/modules/drop.js` (동작) · `css/components/drop.css` (모양) · `index.html` 의 `data-drop` (알약 목록)
- 화면에 들어올 때마다 순서·위치·각도·쏟아지는 방향(왼쪽/오른쪽/가운데/고르게)이 무작위로 달라집니다.
- **톡 누르면** 통 튀어 오르고 이웃도 들썩입니다. **꾹 누른 채 끌면** 집어서 옮기거나 던질 수 있습니다.
  휴대폰에서는 알약 위에서 바로 쓸어 넘기면 평소처럼 스크롤되고, 잠깐(0.17초) 누르고 있다가 움직이면 집힙니다.
- 양옆 벽은 아래 흰 카드의 좌우 끝과 같고, 바닥은 흰 카드 바로 위입니다. 뒤집힌 알약은 글자가 거꾸로 서지 않게 돌려 그립니다.
- 알약 추가/삭제/문구/색은 `index.html` 의 `li` 만 고치면 됩니다 (`--bg` 배경색, `--fg` 글자색).
- 떨어지는 간격, 꾹 누르는 시간 같은 느낌 값은 `drop.js` 맨 위 `TUNE` 에서 바꿉니다.
- '모션 최소화' 설정이거나 JS 가 꺼져 있으면 피그마 배치 그대로 멈춘 모양으로 보입니다.

## 반응형 방식

- 피그마 원본 폭 **860px** 기준입니다. CSS 변수 `--u` 가 "디자인 1px" 이고, 화면이 860px보다 좁으면 비율대로 줄어듭니다.
- 글자는 너무 작아지지 않게 `max(최소px, 디자인값 × --u)` 로 최소 크기를 둡니다.
- 600px 미만(휴대폰)에서는 겹치는 요소(히어로 알약, 프론트/터미널 설명)를 따로 정리하고, 쏟아지는 알약은 글자가 읽히는 크기로 키웁니다.
- 860px 보다 넓은 화면에서는 가운데 860px 칼럼 + 섹션 배경은 화면 끝까지 채웁니다.
- 이미지 위치를 바꾸고 싶으면 HTML 의 `style="--x: ..; --y: ..; --w: .."` 숫자(피그마 좌표)를 고치면 됩니다.

## 넷리파이 배포

- **Git 연결**: 넷리파이에서 이 저장소를 연결하면 `netlify.toml` 대로 `public` 폴더가 배포됩니다. 빌드 명령 없음.
- **드래그 앤 드롭**: https://app.netlify.com/drop 에 `public` 폴더를 끌어다 놓아도 됩니다.

## 지금 상태 (디자인·문구 컨펌용)

- **시트·슬랙 미연결**: `public/js/config.js` 의 `FORM_ENDPOINT` 가 비어 있어 테스트 모드입니다.
  신청 폼은 끝까지 눌러볼 수 있지만 실제 전송은 안 되고, 상단 바는 숫자 없이 "많은 사장님이 관심있게 보고 있어요"로 나옵니다.
- **네이버 전환 스크립트 미설치**: 컨펌 중 방문이 통계에 섞이지 않도록 빼두었습니다 (`index.html` 맨 아래 TODO).
- 피그마 문구 중 오타로 보이는 곳은 고쳐서 넣었습니다. 원문 그대로가 맞다면 `index.html` 에서 되돌리면 됩니다.
  - 히어로 알약 `월 이용로 0원~` → `월 이용료 0원~`
  - 후기 제목 `대표님들이 페이앤밴이 상담 하고 있어요` → `대표님들이 페이앤밴과 상담하고 있어요`
  - 후기 `네이버 리뉴 등록률` → `네이버 리뷰 등록률`
  - 터미널 설명 `확인거나` → `확인하거나`
  - 기능 캐러셀 4번째 슬라이드 번호 `3` → `4`
